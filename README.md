# 🇷🇼 FIN-GAP RWANDA
**District & Sector Financial Exclusion Mismatch Tool**
*A project developed for the NISR Big Data Hackathon 2026 (Track 2: Financial Inclusion & Poverty Reduction).*
### 📌 Overview
FIN-GAP RWANDA is an interactive, data-driven dashboard designed to help policymakers identify where financial inclusion strategies are failing the most vulnerable populations. By cross-analyzing poverty rates (EICV7) with financial access data (FinScope), this tool calculates the **"Mismatch Gap"**—highlighting districts where poverty is high, but financial exclusion is disproportionately worse.
### 🚀 Key Features
*   **Mismatch Matrix:** A visual scatter plot identifying "Severely Underserved" vs "Well-Served" districts.
*   **Interactive District Map:** Geographic heatmaps visualizing exclusion risks across all 30 districts.
*   **Policy Simulator:** An interactive model that allows users to adjust variables (like phone penetration or agent density) to simulate the real-world impact on financial exclusion.
*   **Actionable Policy Briefs:** Automated, data-backed recommendations aligned with Rwanda's NST2 objectives.
### 🛠️ Tech Stack
*   **Frontend:** React.js, Chart.js, Leaflet (Maps)
*   **Backend:** PHP API Router
*   **Database:** PostgreSQL
